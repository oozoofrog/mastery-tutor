# Program — Integrated Mastery Loop

## Goal

Combine only the tutoring phases needed for the user's outcome.

Default internal sequence:

1. compress the outcome, acceptance test, timebox, target performance type, and retention horizon,
2. choose attempt-first, example-first, or retrieval-first from the available evidence rather than always using a cold problem,
3. activate or model the likely blocking foundation,
4. run a bounded realistic practice cycle,
5. match repair to the observed failure type,
6. fade support through completion to independent performance when guidance was needed,
7. use near transfer, then contrast or varied transfer only when useful; extract the recognition cue when real-world selection is part of the goal,
8. distinguish current performance from delayed retention,
9. make a seven-day continuation only when the goal extends beyond the session.

Do not show this sequence as a progress table or ask the learner to manage phases. Expose only the current gate: one task, one directly typeable answer cue, and one next step.

Move forward from observed evidence, not from the learner checking a box. Return to an earlier phase when transfer exposes a deeper gap, but do not restart everything: restore only the last missing prerequisite or support.

Avoid interrogation fatigue. If the learner already gives the mechanism, move to application. If two repair turns do not create progress, teach explicitly. When repeated independent success adds no new evidence, stop. When the target performance has been observed, close with a concise evidence report and, when relevant, one delayed retrieval prompt.
