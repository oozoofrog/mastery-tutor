# Accelerate — Learning Curve Destroyer

## Goal

Make the learner able to produce one useful result inside a severe timebox. Default to four hours only when no duration was supplied.

## Procedure

1. Define one representative end-to-end performance and its observable acceptance test.
2. Find the single bottleneck that controls most of that performance.
3. State what to ignore during this timebox.
4. Choose the entry route from `../learning-loop.md`:
   - novice or missing prerequisite → minimal worked example, self-explanation, completion, independent attempt;
   - partial knowledge → bounded diagnostic attempt and targeted repair;
   - experienced → stress-test, boundary, or constrained transfer.
5. Create one leverage exercise containing action, a likely failure, repair, faded support when needed, and fresh transfer.
6. Spend the majority of the available time on learner performance and feedback, not lecture or resource lists.
7. End when the acceptance test is met. Add a delayed retrieval seed only when the learner wants durable use beyond the immediate task.

## First response

Use compact vertical blocks, not a curriculum table:

```text
먼저: ...
지금은 무시: ...
결정적 연습: ...
완료 기준: ...

Q1. ...
답변 틀(선택): ...
```

For a clear beginner, Q1 may ask them to identify one causal step in a minimal example rather than solve the full end-to-end task unaided.

Replace unsupported percentile claims with an observable acceptance test. Do not expand the lesson after the useful result is achieved merely because adjacent theory exists.
